# Motion Storyboard

Create a visual storyboard pack for short-form motion graphic content. Default to Thai user-facing output, vertical 9:16 TikTok/Reels/Shorts format, and a practical creator-friendly style unless the user specifies otherwise.

## Core Rule

Always produce a storyboard image for normal 6-9 frame storyboards. Do not stop at written shot descriptions. Ask before image generation only when the user requests more than 9 frames or multiple visual variants.

## Quick Workflow

1. Extract or infer the brief:
   - Topic or rough idea.
   - Target audience.
   - Platform and aspect ratio, default `TikTok/Reels 9:16`.
   - Length, default `15-30 seconds`.
   - Tone or visual style, default `practical, clear, creator-friendly`.
   - CTA, if any.
2. State brief assumptions briefly when the user did not provide them.
3. Draft the story structure: hook, beats, reveal, proof, CTA.
4. Convert the structure into 6-9 frames using `references/storyboard-frame-schema.md`.
5. Choose or adapt a style from `references/style-presets.md`.
6. Write per-frame image prompts and motion prompts using `references/prompt-patterns.md`.
7. Generate one storyboard image sheet:
   - One page.
   - 6-9 vertical 9:16 panels.
   - Numbered panels.
   - Short frame labels.
   - Clear visuals that guide editing.
8. Deliver the Hybrid Creator Pack:
   - Brief assumptions.
   - Story structure.
   - Storyboard image.
   - Frame table.
   - Image prompts.
   - Motion prompts.
   - Thai voiceover with rough timing.
   - Caption and hashtags.
   - Production notes.
9. Offer one focused revision pass.

## Output Format

Use this order:

1. `Assumptions`
2. `Story Structure`
3. `Storyboard Image`
4. `Frame Table`
5. `Image Prompts`
6. `Motion Prompts`
7. `Voiceover`
8. `Caption`
9. `Production Notes`
10. `Revision Options`

## Reference Loading

- Read `references/storyboard-frame-schema.md` for frame fields before producing the frame table.
- Read `references/style-presets.md` when the user does not provide a visual style or asks for style options.
- Read `references/prompt-patterns.md` before writing image or motion prompts.

## Revision Behavior

When revising, change only the requested dimension unless the user asks for a full rebuild. Common revision dimensions:

- Faster pacing.
- More premium visuals.
- Simpler visuals for CapCut or Canva.
- Stronger hook.
- Clearer CTA.
- More Thai-local small-business context.

# Storyboard Frame Schema

Use this schema for each frame in the storyboard table.

## Required Fields

| Field | Purpose |
| --- | --- |
| Frame | Sequential number, usually 1-9. |
| Time | Rough timestamp or duration, such as `0:00-0:03`. |
| Beat | Story role: hook, problem, reveal, step, proof, CTA. |
| Visual | What the viewer sees. |
| Text Overlay | On-screen text, short enough for mobile. |
| Motion | Camera movement, animation, transition, and pacing. |
| Voiceover | Spoken line for this frame. |
| Asset Notes | Props, UI screenshots, icons, product images, or footage needed. |

## Default 6-Frame Structure

1. Hook: pattern interrupt, strong visual contrast, clear promise.
2. Problem: show the pain or mistake.
3. Reveal: introduce the method, tool, or idea.
4. Step: show the first practical action.
5. Proof: show result, comparison, or before-after.
6. CTA: tell the viewer what to do next.

## Default 9-Frame Structure

1. Hook.
2. Pain.
3. Stakes.
4. Reveal.
5. Step 1.
6. Step 2.
7. Proof.
8. Summary.
9. CTA.

## Mobile Text Rules

- Keep overlay text under 8 Thai words when possible.
- Put only one idea per frame.
- Use large, high-contrast text.
- Avoid covering faces, products, or key UI elements.
```

# Style Presets

Choose one preset by default, or blend two when the user asks for a specific mood.

## Practical Creator

Best for daily TikTok/Reels education.

- Clear mobile-first composition.
- Bright neutral background with one accent color.
- Big Thai text overlays.
- Simple icons, screenshots, arrows, and callouts.
- Fast cuts and light zooms.

## Clean Tech Explainer

Best for AI tools, Canva, CapCut, Google Drive, PDFs, and beginner tech tips.

- White or light gray base.
- Blue, teal, or yellow accents.
- UI panels, cursor highlights, screen mockups.
- Smooth slide transitions and zoom-to-detail moments.

## Small Shop Reality

Best for small sellers, print shops, local shops, and practical business content.

- Real desk, phone, printer, packaging, storefront, receipts, chat screenshots.
- Warm but not overly decorative color.
- Before-after comparisons.
- Motion emphasizes daily work and practical payoff.

## Premium Pitch

Best for polished offers, productized services, or client-facing explainer clips.

- Dark or clean studio background.
- Strong contrast.
- Fewer words per frame.
- Smooth camera moves, elegant wipes, and controlled pacing.

## Urgent Fix

Best for mistake, warning, checklist, and problem-solution videos.

- Bold contrast.
- Red or yellow warning accents.
- Quick cuts.
- Punchy text overlays.
- End with a concrete fix.
```

# Prompt Patterns

Use these patterns to keep visual and motion outputs consistent.

## Storyboard Sheet Image Prompt

```text
Create a one-page motion graphic storyboard sheet for a vertical 9:16 short-form video.
Include [FRAME_COUNT] numbered vertical panels arranged in a clean grid.
Each panel must show a distinct scene and a short readable label.
Visual style: [STYLE_PRESET].
Topic: [TOPIC].
Audience: [AUDIENCE].
Story beats: [BEATS].
Use clear composition, mobile-first framing, high contrast text areas, and production-ready visual direction.
Do not make it look like a generic mood board. Make it a usable storyboard for editing.
```

## Per-Frame Image Prompt

```text
Frame [NUMBER], [TIME], [BEAT].
Create a vertical 9:16 storyboard frame for a motion graphic video.
Visual: [VISUAL].
Text overlay: [TEXT_OVERLAY].
Style: [STYLE_PRESET].
Composition: mobile-first, clear focal point, readable text area, practical editing reference.
```

## Per-Frame Motion Prompt

```text
Animate frame [NUMBER] from [START_STATE] to [END_STATE].
Camera or layout motion: [CAMERA_OR_LAYOUT_MOTION].
Element animation: [ELEMENT_ANIMATION].
Transition: [TRANSITION].
Pacing: [PACING].
Keep the motion readable on mobile and synchronized with this voiceover: [VOICEOVER].
```

## Voiceover Pattern

```text
[0:00-0:03] Hook line.
[0:03-0:07] Problem or context.
[0:07-0:14] Practical steps or reveal.
[0:14-0:22] Proof, payoff, or summary.
[0:22-0:30] CTA.
```

## Caption Pattern

```text
[One-line value promise]

[Short practical context]

[CTA question or instruction]

#ThaiContent #SmallBusiness #AItools #CapCut #Canva
```
```
